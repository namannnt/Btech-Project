## 2. Fixes Applied

1. **Database Initialization (BUG-001)**: Created `scripts/create_sample_db.py` to seed `backend/data/sample.db` with 6 tables (customers, orders, products, order_items, transactions, sales) and realistic data including relationships.
2. **Intent Agent Prompt Fix (BUG-002)**: Modified `backend/agents/intent_agent.py` to escape JSON examples as `{{"column": "col_name"}}` preventing Langchain `ChatPromptTemplate` from parsing them as variable placeholders.
3. **UNION ALL False Positive (BUG-003)**: Modified `backend/agents/security_agent.py` regex for UNION injection detection to `;\s*UNION\s+(ALL\s+)?SELECT` to properly target stacked malicious statements rather than legitimate aggregated queries.
4. **SQLite Dialect Fix (BUG-004)**: Added `_post_process_candidates` in `backend/agents/sql_generation_agent.py` to correctly rewrite PostgreSQL `DATE_TRUNC` generated by the LLM into SQLite compatible `strftime` queries.
5. **Schema Soft-Pass Advisory (BUG-006)**: Modified `backend/agents/validation_agent.py` to log an explicit advisory warning instead of a silent pass when the schema is empty.
6. **Test Suites Updates**: Updated `tests/test_security_agent.py` so `test_injection_union_select_blocked` correctly passes a stacked query in order to properly test the revised injection filter.
